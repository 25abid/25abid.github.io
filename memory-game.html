Work / CS50P final project

A game of remembering.

Reveal two letters. Find a match and they stay uncovered. Miss, and you have two seconds to remember their positions. Find every pair to win.

Choose two cards to begin.

0 / 6 pairs · 0 turns

Originally written in Python for Harvard’s CS50P. This browser adaptation uses JavaScript and keeps the original letter matching, difficulty settings, and two-second reveal. Letters can appear in more than one pair. Custom grids support 1–10 rows and columns, with an even number of cells.
